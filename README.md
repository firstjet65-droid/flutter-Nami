# NAMI — Интернет-дүкен (Flutter)

## Іске қосу
1. Архивті ашып, `internet_duken` бумасын VS Code-та ашыңыз.
2. Терминал → New Terminal ашыңыз.
3. Командаларды кезекпен орындаңыз:
   ```bash
   flutter doctor
   flutter pub get
   flutter run
   ```
4. Құрылғы таңдаңыз: Android эмуляторы, қосылған телефон немесе Chrome (`flutter run -d chrome`).

## Қазіргі нұсқада бар
- `screens`, `widgets`, `models`, `services`, `data` және `theme` бойынша бөлінген құрылым
- Splash, қош келдіңіз және төрт бөлімді төменгі навигация
- Санаттар, тауарлар тізімі, іздеу және толық тауар ақпараты
- Себет, тауар санын өзгерту және тапсырыстың жалпы сомасы
- Таңдаулыға қосу және таңдаулылардан алып тастау
- Email мен құпиясөз тексерілетін кіру және тіркелу формалары
- Тауарды каталогқа қосу және өңдеу формасы
- Тапсырысты рәсімдеу, сәтті аяқтау және тапсырыстар тарихы
- Профиль, хабарламалар, баптаулар, қараңғы тақырып және көмек экрандары
- REST API арқылы сервер каталогын алу және тауарға POST/PUT/DELETE жіберу
- Телефон мен кең экранға қарай бейімделетін тауарлар торы

## Практикалық жұмыс №5 — REST API
- API: [DummyJSON Products](https://dummyjson.com/docs/products)
- `GET /products?limit=30` — тауарларды алу және SQLite `api_products` кестесіне сақтау
- `POST /products/add` — жаңа тауар жіберу
- `PUT /products/{id}` — тауарды өзгерту
- `DELETE /products/{id}` — тауарды жою
- Экран: Профиль → **REST API каталогы**. Жүктелу, бос нәтиже, сервер қатесі,
  интернетке қосылмау және 12 секундтық timeout күйлері өңделеді.
- DummyJSON — оқу/демо API: POST, PUT және DELETE жауабын қайтарады, бірақ
  сервердегі бастапқы деректерді тұрақты өзгертпейді. Соңғы алынған каталог
  құрылғыдағы SQLite кэшіне сақталады; серверден қайта синхрондау демо API
  берген бастапқы тізімді қайтарады.
- Android үшін интернет рұқсаты негізгі manifest-ке қосылған.

## Ескерту
Бұл — практикалық жұмысқа арналған демонстрациялық жоба. Негізгі дүкендегі тауарлар, себет, таңдаулылар, тапсырыстар және баптаулар құрылғыдағы SQLite дерекқорында сақталады. Кіру мен тіркелу формалары серверлік авторизация емес, төлем тәсілін таңдау да нақты төлем өңдемейді. REST API каталогы оқу мақсатындағы DummyJSON қызметін пайдаланады; оның POST/PUT/DELETE операциялары сервер жауабын көрсеткенімен, өзгерістерді қашықтағы дерекқорда сақтамайды. Тауар суреттері интернеттегі сілтемелерден жүктеледі; интернет болмаса белгіше көрсетіледі.
