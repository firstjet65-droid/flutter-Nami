# NAMI — Интернет-дүкен (Flutter)

## Іске қосу
1. Архивті ашып, `internet_duken` бумасын VS Code-та ашыңыз.
2. Терминал → New Terminal ашыңыз.
3. Командаларды кезекпен орындаңыз:
   ```bash
   flutter doctor
   flutter pub get
   flutter run
   ```
4. Құрылғы таңдаңыз: Android эмуляторы, қосылған телефон немесе Chrome (`flutter run -d chrome`).

## Қазіргі нұсқада бар
- `screens`, `widgets`, `models`, `services`, `data` және `theme` бойынша бөлінген құрылым
- Splash, қош келдіңіз және төрт бөлімді төменгі навигация
- Санаттар, тауарлар тізімі, іздеу және толық тауар ақпараты
- Себет, тауар санын өзгерту және тапсырыстың жалпы сомасы
- Таңдаулыға қосу және таңдаулылардан алып тастау
- Email мен құпиясөз тексерілетін кіру және тіркелу формалары
- Тауарды каталогқа қосу және өңдеу формасы
- Тапсырысты рәсімдеу, сәтті аяқтау және тапсырыстар тарихы
- Профиль, хабарламалар, баптаулар, қараңғы тақырып және көмек экрандары
- Телефон мен кең экранға қарай бейімделетін тауарлар торы

## Тексеру
```bash
flutter analyze
flutter test
```

## Ескерту
Бұл — практикалық жұмысқа арналған демонстрациялық жоба. Тауарлар, себет, профиль және тапсырыстар серверге жіберілмейді, қосымша жабылғанда өшеді. Кіру мен тіркелу формалары серверлік авторизация емес, төлем тәсілін таңдау да нақты төлем өңдемейді. Тауар суреттері интернеттегі сілтемелерден жүктеледі; интернет болмаса белгіше көрсетіледі.
